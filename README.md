# ربات ارسال پیام واتساپ 📱

## راهنمای استفاده

### مرحله ۱: نصب
پروژه رو از گیت‌هاب کلون کن:
```
git clone <repo-url>
cd whatsapp-sender
npm install
```

### مرحله ۲: اجرا
```
node index.js
```

### مرحله ۳: اتصال واتساپ
1. QR کد به تلگرامت ارسال میشه
2. گوشیت رو باز کن
3. Settings → Linked Devices → Link a Device
4. QR کد رو اسکن کن

### مرحله ۴: آپلود فایل اکسل
فایل اکسل با ستون‌های `شماره` و `اسم` بفرست به ربات تلگرام

### مرحله ۵: شروع ارسال
```
/send سلام {name} 👋 مجموعه ما برای شما تخفیف ویژه دارد...
```

## دستورات تلگرام

| دستور | توضیح |
|-------|-------|
| `/start` | نمایش منو |
| `/status` | وضعیت واتساپ |
| `/send متن` | شروع ارسال |
| `/stop` | توقف ارسال |
| `/contacts` | لیست شماره‌ها |
| `/limit` | نمایش لیمیت |
| `/addaccess [ID]` | اضافه کردن دسترسی |
| `/removeaccess [ID]` | حذف دسترسی |
| `/accesslist` | لیست دسترسی‌ها |

## لیمیت‌های امنیتی

- حداکثر ۳۵ پیام در روز
- فاصله ۳-۵ دقیقه بین هر پیام
- ساعات ارسال: ۸ صبح تا ۱۰ شب

## نکات مهم

- ⚠️ از شماره اصلی استفاده کن (نه شماره جدید)
- ⚠️ متن پیام رو متنوع بنویس
- ⚠️ بیشتر از ۳۵ پیام در روز نفرست
- ⚠️ شب‌ها پیام نفرست

## استقرار روی Railway

1. پروژه رو روی گیت‌هاب آپلود کن
2. به railway.app وارد شو
3. پروژه رو اضافه کن
4. متغیرهای محیطی رو تنظیم کن:
   - `TELEGRAM_TOKEN`
   - `ADMIN_IDS`
5. Deploy کن
