# 🤖 WhatsApp Sender Bot

ربات تلگرام برای ارسال پیام واتساپ با کنترل هوشمند

## ✨ امکانات

- 🔗 اتصال واتساپ با QR Code یا Pairing Code
- 📋 آپلود فایل اکسل شماره‌ها (ذخیره دائم در حافظه)
- 📤 ارسال هوشمند با فاصله رندوم ۹۰-۹۰۰ ثانیه
- ⏰ ارسال فقط ۸ صبح تا ۱۱ شب
- 🔄 ادامه خودکار ارسال ناقص از فردا ۸ صبح
- 👤 شخصی‌سازی پیام با اسم مشتری
- 📱 تست ارسال تکی
- 👥 مدیریت دسترسی ادمین‌ها

## 🚀 نصب

### Railway
1. فایل‌ها رو به ریپو GitHub فشار بده
2. Railway → New Project → Deploy from GitHub
3. وریبل‌ها رو تنظیم کن

### وریبل‌های محیطی

| Variable | توضیح | اجباری |
|----------|-------|--------|
| `TELEGRAM_TOKEN` | توکن ربات تلگرام | ✅ |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (با کاما) | ✅ |
| `MY_NUMBER` | شماره خودت برای Pairing (بدون +) | برای /pair |
| `PROXY_URL` | آدرس پروکسی (socks5://...) | اختیاری |

## 📱 کامندها

### اتصال
| کامند | توضیح |
|-------|-------|
| `/qr` | ریستارت + نمایش QR Code |
| `/pair` | ریستارت + کد Pairing |

### ارسال
| کامند | توضیح |
|-------|-------|
| `/upload` | آپلود فایل اکسل شماره‌ها |
| `/clear` | پاک کردن اکسل از حافظه |
| `/send` | ارسال هوشمند (مرحله‌ای) |
| `/resume` | ادامه ارسال ناقص قبلی |
| `/new` | پاک کردن پیشرفت |
| `/stop` | توقف ارسال |
| `/test` | تست ارسال تکی |

### اطلاعات
| کامند | توضیح |
|-------|-------|
| `/status` | وضعیت واتساپ و ارسال |
| `/contacts` | لیست شماره‌های آپلود شده |
| `/limit` | محدودیت‌های ارسال |
| `/accesslist` | لیست ادمین‌ها |
| `/addaccess [ID]` | اضافه کردن ادمین |

## 📤 نحوه ارسال

### ارسال رنج (متوالی)
```
/send
📝 متن: سلام {name} عزیز، تخفیف ویژه داریم!
📏 محدوده: 100-200
✅ تأیید: بله
```

### ارسال لیست دلخواه
```
/send
📝 متن: سلام {name}!
📏 محدوده: 111, 250, 345
✅ تأیید: بله
```

### تست تکی
```
/test
📞 شماره: 989123456789
📝 پیام: سلام تست
```

## ⚙️ الگوریتم هوشمند

- **فاصله ارسال:** ۹۰ تا ۹۰۰ ثانیه رندوم (۱.۵ تا ۱۵ دقیقه)
- **زمان ارسال:** ۸ صبح تا ۱۱ شب
- **ادامه خودکار:** اگه ۱۱ شب بشه و تموم نشده، فردا ۸ صبح ادامه میده
- **ذخیره پیشرفت:** هیچ پیامی تکرار یا گم نمیشه
- **تشخیص اسپم:** فاصله رندوم باعث میشه واتساپ اسپم تشخیص نده

## 🔧 اتصال واتساپ

### روش QR Code
1. `/qr` بزن
2. QR Code عکس PNG میاد
3. واتساپ → Settings → Linked Devices → Link a Device
4. اسکن کن

### روش Pairing Code
1. وریبل `MY_NUMBER` رو تنظیم کن
2. `/pair` بزن
3. کد ۸ رقمی میاد
4. واتساپ → Settings → Linked Devices → Link with Phone Number
5. کد رو وارد کن

## ⚠️ نکات مهم

- از واتساپ اصلی (نه بیزنس) استفاده کن
- حداکثر ۳۰-۵۰ پیام در روز بفرست
- پیام‌ها رو شخصی‌سازی کن (اسم مشتری)
- از ارسال انبوه خودداری کن
- فقط به شماره‌هایی بفرست که رضایت دارن
